# 前端验收

整理于 2026-10-17；浏览器检查于 2026-10-16 完成。布局验证使用明确标注的固定样例，流式进度使用真实查询，不将样例报价作为实时数据证据。

## 当前实现

- 字号与间距使用 CSS 变量统一维护，筛选项的勾选框、标签、数量独立对齐。
- 窄屏平台卡使用横向信息行，完整显示报价小数；样例说明与按钮分行。
- 长商品标题可原生展开；图片加载失败保留图标、说明及可访问名称。
- 对比表提供横向滚动提示、键盘聚焦区域及固定的对比项列。
- 预算与价格区间提供持续的字段错误提示；无效草稿不覆盖最后有效条件，两个更新入口均禁用。修正后恢复操作且输入不失焦。
- 桌面执行序号使用同一个 SVG 绘制圆圈、数字及勾选，避免普通文字样式覆盖居中。前端资源带版本参数。
- 键盘跳转链接聚焦搜索框；移动表单字号 16px，避免常见手机浏览器聚焦放大。

## 已验证

| 场景 | 证据 |
|---|---|
| 320、390、768、1280px 结果页 | 文档宽度等于视口宽度，无整页横向溢出 |
| 手机平台报价 | `¥204.82` 单行完整显示，见 [移动端截图](img/mobile.jpg) |
| 筛选无结果 | 展示空结果、提示旧推荐并隐藏旧购买按钮；清空筛选恢复候选 |
| 长标题与商品对比 | 可展开完整标题；选择两件商品可打开对比弹窗 |
| 倒置价格区间与负预算 | 持续提示错误并禁用更新；修正后一次点击可更新 |
| 1600px 桌面真实进度 | 数字 2–6 与 SVG 的边界框中心横纵偏差均为 0，见 [桌面进度截图](img/progress.jpg) |
| 自动回归 | Node 原生测试 21 项通过，覆盖筛选、金额边界、输出转义、URL 与 SSE 消费 |

人工浏览器验证不替代持续集成中的端到端自动化。代码与人工检查分别提供证据，不以纯函数测试推断整个界面已通过测试。
