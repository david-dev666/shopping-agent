# frontend

当前界面由 FastAPI 托管，无需安装前端依赖或构建：

- `backend/static/index.html`：语义化页面、搜索与对比弹窗
- `backend/static/styles.css`：视觉系统、桌面与手机布局
- `backend/static/app.js`：查询、筛选、重排、错误恢复、对比与最近搜索
- `backend/static/stream.mjs`：SSE 分帧、UTF-8 增量解码与执行进度消费
- `backend/static/helpers.mjs`：筛选、排序、链接及商品标识等纯函数

启动方式见根目录 README。界面支持智能选购 / 直接比价、平台与标题特征筛选、价格区间、警示排除、最多三件商品对比及执行记录。

筛选立即作用于报价列表；点击“更新推荐”后才同步首选和理由。筛选变更时旧推荐有显式提示并收起购买按钮。手机端优先展示推荐，筛选折叠。默认真实查询；“体验选购样例”是独立入口。来源徽标区分本次采集、缓存报价和固定样例，数据源说明位于右上角面板。

在仓库根目录运行前端逻辑测试（Node.js 22+，无 npm 依赖）：

```bash
node --check backend/static/app.js
node --test frontend/tests/*.test.mjs
```

覆盖跨平台 ID、组合筛选、索引映射、预算与警示、外部 URL / 文本及损坏历史数据。完整浏览器端到端自动化仍在根目录 `TODO.md` 中跟踪。

视觉规范：辅助信息 12px、正文与常规控件 14px、商品及卡片标题 16px、区块标题 20px，使用 CSS 变量维护；移动端保持文字层级，通过换行和网格调整布局。筛选勾选行使用独立的勾选框、标签、数量三列，不复用字段标题的样式。

结果页的需求编辑器支持预算及选购侧重，移动端默认折叠。输入事件不重建控件，避免失焦或第一次点击“更新推荐”被吞掉。筛选重置保留已编辑的选购要求。

智能选购消费 `/api/chat/stream` 的真实节点事件；样例不模拟执行进度。“直接比价”使用 5 分钟查询缓存，“重新采集”显式绕过缓存。停止任务会关闭进度流并协作停止后续节点，当前在途请求可能仍需结束。

价格与预算使用字段下方持续提示，关联 `aria-describedby` / `aria-invalid`。错误草稿不覆盖最后有效输入，未修正前禁用两个重排入口；校验不弹出逐键浏览器提示，不重建输入控件。金额支持空值、零和最多两位小数。
