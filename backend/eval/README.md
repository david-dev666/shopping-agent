# 小规模 AI 辅助评测

由 Codex 阅读真实采集的标题与报价并写下标签和依据，不要求用户组织人工标注、抽查或凑满 200 组。不增加自动评审服务、模型供应商配置或标注平台。

当前 `ai_pairs.jsonl` 有 20 例历史真实采集样本，由 Codex 依据原始文本逐例评阅后再运行规则；包含版本冲突、混卖、配件、预算不足与缺失标题。样本是为了覆盖边界而挑选，来自两个需求，不代表线上分布；此前已用于开发，**不是独立保留集，也不是真实 SKU 或成交价的准确率评测**。

## 运行

在 backend 目录执行，无需 key 或模型调用：

```bash
.venv/bin/python scripts/eval_pairs.py
```

需要同时测推荐时，复用现有重排流程；先重算警示标签，AI 标签和评阅依据不传给模型。配置了模型会实际调用，未配置或失败时沿用规则降级，报告列出实际决策引擎：

```bash
DATABASE_URL=sqlite:////tmp/shopping-ai-eval.db .venv/bin/python scripts/eval_pairs.py --run
```

脚本输出 JSON，可用重定向保存。`--dataset` 可指定另一份同结构的小样本，不设置最小数量门槛。默认评测不写数据库，`--run` 的轨迹写入指定数据库。

## 标签与结果

- `title_match`：参考与候选**已明确声明的型号 / 版本等属性**是否一致，不是已确认同一实际 SKU。缺少关键属性或混卖标 null。
- `suitable`：就给出的标题与采集报价，是否满足原始需求；明确超预算、型号不符或配件标 false，关键条件不明标 null。true 不构成购买保证。
- `reviewer=codex`、`evidence`：记录 AI 来源和逐例理由，保留原始标题、链接和采集时间。没有重新访问详情页，不验证现时库存、店铺身份、优惠资格或成色。

报告明确 `independent_ground_truth=false`。precision / recall 和 agreement 只表示系统规则与 AI 弱标签的关系，待确认标签不计入分母；同时输出已标数量、待确认数量及覆盖率。

推荐的 Top-1 合适率 / 错误推荐率只统计 AI 可以判断的实际首选，另列未判断首选、未推荐及查询覆盖率；没有运行推荐就不生成推荐指标。不能把待确认或全部不推荐算成全部正确。

后续由 Codex 小批补充失败案例和依据即可；改过标签的案例应视为开发回归，不宣称独立泛化结果。原有 `rules_eval.jsonl` 继续用于规则回归，与 AI 弱标签评测分别报告。
